비주얼 사고력의 근거

브랜드 1년이 프로덕트 1년의 정보 위계·시스템 사고로 어떻게 이어졌는지

각 클라이언트의 브랜드 문제를 시각 언어로 번역한 작업은, 지금 프로덕트 화면에서 사용자에게 의도를 한 번에 읽히게 만드는 감각으로 이어졌습니다.

다양한 산업군의 브랜드를 다루며, 핵심 메시지를 빠르게 읽어내고 이를 일관된 시각 언어로 구조화하는 역량을 길렀습니다. CI/BI와 콘텐츠 디자인 경험은 제품 안팎에서 브랜드 경험을 설계하는 감각과 실행력을 키워주었습니다.

02 Brand → Product

브랜드 → 프로덕트 전환에서
가져온 3가지 근육

1. 정보 위계

우표전시회 캠페인 가족 타깃 · 폰트·배치 위계
→
정보 위계 시각 우선순위 결정
→
클럽미니쉬 스텝 바 단계를 3초 안에 읽히게

우표전시회 캠페인에서 가족 타깃을 위해 폰트 크기·배치로 시각 위계를 잡던 경험이, 클럽미니쉬 스텝 바 UI 설계로 이어졌다.

2. 시스템적 사고

한샘 SNS 콘텐츠 톤앤매너 일관성 규칙
→
시스템적 사고 규칙 기반 설계
→
디자인 시스템 컴포넌트·토큰 규칙 정의

한샘 SNS 콘텐츠에서 톤앤매너 일관성 규칙을 수립하던 경험이, 클럽미니쉬 디자인 시스템 컴포넌트·토큰 정의로 직결됐다.

3. 클라이언트 의도 번역

B2C 캠페인 브리프 → 시각 언어 번역
→
의도 번역 목표 → 결정
→
PM 요구사항 번역 의도 → UI 결정

B2C 캠페인에서 클라이언트 브리프의 비즈니스 목표를 시각 언어로 번역하던 경험이, PM 요구사항을 UI 결정으로 풀어내는 방식으로 이어졌다.
