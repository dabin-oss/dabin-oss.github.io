01 · App Overview

실제로 출시된 앱

클럽미니쉬는 미니쉬 치과의 기존 고객이 지인을 초대하고, 상담 예약부터 리워드 수령까지 하나의 앱에서 처리할 수 있는 멤버십 기반 헬스케어 서비스입니다.

01
최상급 웰니스라이프 커뮤니티
회원 전용 홈화면 — 초대장, 혜택, 리더보드, 내 미니쉬 탭으로 구성
02
회원만을 위한 특별 세미나 초청
VIP 초대장 — 등급별 혜택 접근성 차별화
03
다양한 안티에이징/메디컬 브랜드 혜택
제휴 브랜드 쿠폰 및 혜택 목록 — 카테고리별 탭 구조
04
최대 10년 A/S 보증 모바일 정품인증서
시술 후 발급되는 디지털 보증서 — 시술 정보, 보증 기간, 주치의 정보 포함
05
등급이 오를수록 업그레이드 되는 혜택
초대 실적 기반 리더보드 + 스마일 포인트 — 등급제 게이미피케이션
06
1분만에 서비스 및 상담 예약
날짜 + 시간 통합 선택 화면 — 가용 슬롯 실시간 연동
02 · Design System

일관된 경험을 위한 디자인 시스템

0→1 프로젝트이기 때문에 컴포넌트 하나하나를 처음부터 정의했습니다. 개발자와의 협업 효율을 높이기 위해 컬러, 타이포, 간격 시스템을 먼저 확정하고, 이를 기반으로 모든 화면을 설계했습니다.

01
Grayscale 10단계
배경·카드·텍스트를 위한 10단계 그레이스케일 팔레트. 일관된 계층 구조를 위해 토큰 단위로 정의했습니다.
02
4px 스페이싱 시스템
모든 여백과 간격을 4px 단위로 통일. 개발자가 수치를 직관적으로 읽을 수 있도록 설계했습니다.
03
한/영 타이포그래피
한국어(Pretendard)와 영어(Roboto) 타입페이스를 각각 지정하고, 6단계 타입 스케일을 정의했습니다.
Grayscale Palette
Spacing System
Typography · Korean
Typography · English
03 · Dev Collaboration

설계가 서비스로 구현되기까지

해외 개발팀과의 협업이었기 때문에, 명확한 핸드오프 문서와 영어 커뮤니케이션이 핵심이었습니다. Figma Dev Mode를 적극 활용해 개발자가 스펙을 직접 읽을 수 있도록 했습니다.

Figma Dev Mode 핸드오프
컴포넌트별 스펙, 인터랙션, 상태값을 Figma Dev Mode에서 직접 확인할 수 있도록 정리. 별도 스펙 문서 없이 Figma만으로 개발 가능한 구조를 만들었습니다.
Figma Dev Mode Auto Layout 컴포넌트 스펙
QA · 이슈 트래킹
런칭 전 기기별 QA를 직접 진행. 디자인 의도와 다르게 구현된 부분을 스크린샷 기반으로 피드백하고, 런칭 첫 주 이슈 대응까지 참여했습니다.
기기별 QA 이슈 트래킹 런칭 대응
해외 개발팀 커뮤니케이션
해외 개발자와 영어로 직접 소통. 디자인 의도를 명확히 전달하기 위해 텍스트 설명보다 시각적 레퍼런스와 플로우 다이어그램을 적극 활용했습니다.
영어 커뮤니케이션 Slack 플로우 문서
운영 개선 · 런칭 후 피드백
출시 후 실사용 피드백을 바탕으로 예약 플로우를 개선. 운영자 인터뷰를 통해 수동 처리 포인트를 파악하고 UX 개선안을 도출했습니다.
사용자 피드백 운영 인터뷰 반복 개선
Phase 1
기획 · 설계
IA · 플로우 · 와이어프레임
서비스 구조 정의 → 사용자 플로우 설계 → Lo-fi 와이어프레임으로 구조 검증. PM과 주 2회 싱크를 통해 비즈니스 요구사항과 UX 균형을 맞췄습니다.
Phase 2
디자인 시스템
컬러 · 타이포 · 컴포넌트 정의
Grayscale, Spacing, Typography 시스템을 먼저 확정한 뒤 화면 설계에 진입. 재사용 가능한 컴포넌트를 Figma에서 토큰 기반으로 구축했습니다.
Phase 3
개발 협업
핸드오프 · 구현 검토 · QA
Figma Dev Mode로 스펙 전달 → 개발 구현 검토 → 기기별 QA. 해외 개발팀과 Slack 영어 커뮤니케이션으로 실시간 피드백 루프를 유지했습니다.
Phase 4
런칭 · 운영
앱스토어 출시 · 피드백 반영
iOS · Android 동시 출시 후 첫 주 이슈 대응. 실사용 피드백 기반으로 예약 플로우를 개선했고, 이 과정이 케이스스터디의 핵심 내용입니다.
